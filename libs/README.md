# libs

`Opsis.UI.dll` - the shared flat controls (FlatButton, FlatCheckBox, FlatSlider, FlatComboBox, FlatTabs, theme tokens) of the Opsis family.
Source, tests and the adoption notes: `C:\w\Opsis.UI` (git). The DLL is committed here so a clone of this repository builds without it.
To update: build `C:\w\Opsis.UI\src\Opsis.UI` in Release and copy the DLL over this one, then run the tests.
Built from the Opsis.UI commit named in `Opsis.UI.version.txt`.
