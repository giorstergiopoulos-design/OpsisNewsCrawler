## Done in 0.14.3 — rectangular icon
Before/after: `docs/img/bar-icon-before-0.14.2.png`, `docs/img/bar-icon-after-0.14.3.png`.
- Breaking-news intro: the icon was a square tile of the bar height whose artwork (bar with four tiny symbols) was ~40 % of it, plus a circular echo ring.
  Now a 4:1 rounded rectangle (radius = ⅕ of the height) with all four symbols large, over the full bar height, and a rounded-rectangle ring. Rendered at the
  final pixel size and only scaled down while it grows, so it is crisp at every DPI. **V** (snapshot at 42/63/84 px and live on a 2560 px screen).
- Settings header: same wide icon (was 32×32 square). **V**.
- Letter badges and favicon plates: rounded squares instead of circles. Favicons decoded and kept at 64 px (aspect kept, never cropped) and scaled down;
  the icon beside a headline is 20 px at 42 px bar height and grows with the bar (was fixed 16 px). **V** for badges/plate, **I** for real favicons (no network in the test).
- Unchanged on purpose: tray icon and Windows title-bar icon (Windows requires square), shape setting (rect/rounded/pill), hit-testing (item rectangles do not depend on the icon), live button, weather click. Not retested by clicking.
- Logic that is testable moved to `Core/IconGeometry.cs` (+11 unit tests, 113 total).

## Quality notes
- **Localisation**: all 14 locale files have the same 488 keys, 0 missing (**V**, scripted). Quality of the 12 non-Greek/English files was not reviewed by a native speaker. The settings page names ("Μπάρες", "Εμφάνιση", …) in the nav rail are translated; a few Greek strings are long enough to risk clipping in German/Russian — not checked at runtime (**I**).
- **Robustness**: network code catches the documented exceptions and feeds are size-capped (**I**). Missing: a visible per-feed error, retry with backoff, and a test for the title-normalisation that proposal 2 needs.
- **Memory/CPU**: the intro bitmap is cached per size and disposed with the canvas; favicons are now 64×64×4 B each (16 KB/host, negligible). Low-power mode lowers the frame rate (per changelog 0.14.0, not measured here).
- **Multi-monitor / DPI**: bars follow `DisplaySettingsChanged`; per-monitor extra bars exist (**I**). The wide icon follows the canvas pixel height, so it follows DPI automatically (**V** in the 63/84 px rows only as simulated heights, not on a real 150/200 % monitor).
- **Tests missing**: layout/hit-test maths lives in WinForms code and is untested (extract like `IconGeometry`); locale-key parity should be a unit test (a 10-line test would have replaced my script); no test for item de-duplication, source health or the update flow beyond hashing.

## Overlap / candidates to remove or merge
- Two ways to open the analysis tools (tray and Sources → Markets) and two settings-export routes (settings buttons and OPML) — keep, but label them clearly.
- The pill/rounded/rect shape setting, outline radius and edge fade interact (three controls for one look): merge into one "style" choice with presets (Glass, Solid, Minimal).
- The animated tray icon, animated header icon and animated title-bar icon duplicate each other; one switch is enough.
- Market-analysis assistant and "news mood" are heavy for a ticker; consider moving them behind an opt-in "Advanced" group.

## Not verified
Real favicon rendering, clicks on the live/weather/headline targets after the change, 125/150/200 % on a real monitor, taskbar-integrated placement beside the Windows 11 taskbar (the live check used the *Top* position of the throw-away config), RTL languages with the wide intro icon (it is centred, so I expect no issue).
