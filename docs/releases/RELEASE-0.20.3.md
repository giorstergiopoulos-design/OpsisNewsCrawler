# Opsis News Crawler 0.20.3

## Ελληνικά
- **Υγιεινή εκδόσεων**: τα αρχεία δεν κρατούν ίχνη του μηχανήματος build (διαδρομές, όνομα χρήστη, email), όλα δηλώνουν τον ίδιο εκδότη (giorstergiopoulos-design), το setup απαιτεί Inno Setup 7.
- **Ο ενημερωτής δεν ξεκινά κρυφό PowerShell**: το ίδιο το πρόγραμμα (`--apply-update`) ελέγχει το SHA-256 και τρέχει το setup με έγκριση UAC.
- Άδεια: τυπικό MIT.

## English
- **Release hygiene**: files carry no trace of the build machine (paths, user name, e-mail), all name the same publisher (giorstergiopoulos-design), the setup requires Inno Setup 7.
- **The updater starts no hidden PowerShell**: the program itself (`--apply-update`) checks the SHA-256 and runs the setup with a UAC prompt.
- Licence: the standard MIT text.
