# Opsis News Crawler 0.20.1

## Ελληνικά
- **Επέκταση του συμβολαίου plugin** (προαιρετική, η έκδοση assembly παραμένει 0.8.0.0): `PluginWidget`, `IPluginWidgetProvider`, `PluginFeedItem`, `PluginFeed`, `PluginFeeds`. Ένα plugin μπορεί να καταχωρεί ροές κειμένου που ο χρήστης επιλέγει ως περιεχόμενο μπάρας (Ρυθμίσεις > Μπάρες) και widgets για την επιφάνεια του Opsis.
- Νέο project tests που φορτώνει το δικό τους αντίγραφο του συμβολαίου και συγκρίνει όλες τις δημόσιες υπογραφές.

## English
- **Plugin contract extended** (optional; the assembly version stays 0.8.0.0): `PluginWidget`, `IPluginWidgetProvider`, `PluginFeedItem`, `PluginFeed`, `PluginFeeds`. A plugin can register text feeds that the user picks as the content of a bar (Settings > Bars) and widgets for the Opsis desktop.
- A new test project loads the plugin's own copy of the contract and compares every public signature.
